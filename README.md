## インストール方法(Android)

このアプリはGoogle Playで配布していないため、APKを直接インストールします。

> ⚠️ 2026年秋以降、Googleの「開発者検証」により、未登録の開発者のアプリは
> 通常より手間のかかる手順が必要になります。これはAndroid側の仕様で、
> 本アプリ固有の制限ではありません。地域や端末によっては表示されず、
> 従来どおりインストールできる場合もあります。

### 方法A: Androidの「詳細フロー」を使う(初回のみ)

1. 設定 → デバイス情報 →「ビルド番号」を7回タップして開発者向けオプションを有効化
2. 開発者向けオプション →「未確認の開発者のアプリを許可」をオン
   (項目名は端末やバージョンで異なる場合があります)
3. 警告を読み、「誰かに強要されていない」ことを確認
4. 端末を再起動
5. **24時間待つ**
6. 同じ画面に戻り、生体認証またはPINで本人確認
7. 許可期間を「7日間」か「無期限」から選択
8. APKを開き、「とにかくインストール」をタップ

補足:
- 手順完了後は、開発者向けオプションをオフにして構いません。
- 待機は初回のみです。
- **アップデートにも同じ設定が必要です。** 設定をオフにすると更新に失敗します。

### 方法B: ADBでインストールする(待機なし)

PCとUSBデバッグを使う方法です。24時間の待機は不要です。

```
adb install ELSTReVanced_V1.1.apk
```
apkは[Release](https://github.com/RADEON6800/ELST-ReVanced/releases)ページからダウンロードしてください。



    
## ビルド
Android Studioでビルドします。
依存関係の設定　`app/build.gradle` の `dependencies` に Xposed API を追加（必ず `compileOnly` にすること）
リリースのapkはXposedモジュールと改造apkをNPatchで包んたものですが、NPatchは必ずv1.0.6以前の物を使用してください。  
最新版ではAPI100以前のモジュールが使用不能になっています。
